# Reflection

## The most difficult concept

The hardest part of the course for me was the coding and finishing the daily projects. Code has to be exact: one missing letter or a wrongly named file stops everything from working. I struggled with Git at first, for example when I pushed folders named "day 4" and "day 5" with spaces and had to rename them. I overcame this by working one step at a time, checking the result after each step, and reading error messages instead of guessing. Commands like git status and git ls-files showed me exactly what was wrong.

## What I would improve in my capstone

I would improve my capstone by going into more detail and adding more options. The feedback I received was [i need to personalize my work more]. To act on it, I would explain each part more fully so that anyone reading it understands the choices I made, and I would add more options for users, which would make the project more complete and more useful.
